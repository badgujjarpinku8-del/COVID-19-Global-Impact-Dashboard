# COVID-19 Global Impact Dashboard

## Project Overview
This project analyzes historical COVID-19 data across India, United States, Brazil and United Kingdom using Python.

## Objectives
- Analyze COVID-19 cases and deaths.
- Compare country-level trends.
- Study vaccination coverage.
- Calculate cases and deaths per million.
- Analyze seven-day rolling averages.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Plotly
- Google Colab

## Key Features
- Data cleaning and preprocessing
- Missing-value handling
- Population-adjusted metrics
- Interactive visualizations
- Country comparison
- Executive summary report

## Dashboard Visualizations
1. COVID-19 Cases Per Million
2. COVID-19 Deaths Per Million
3. Vaccination Coverage
4. Seven-Day Average New Cases

## Dataset
Source: Our World in Data  
https://ourworldindata.org/coronavirus

## Project Deliverables
- Cleaned CSV dataset
- Interactive Google Colab notebook
- Four data visualizations
- Executive Summary PDF

## Conclusion
This project demonstrates practical data analytics skills, including data cleaning, metric calculation, visualization and communicating insights from historical COVID-19 data.
